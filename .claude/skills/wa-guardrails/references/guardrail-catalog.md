# 統制手段と限界の早見表

| 統制手段 | 予防できる範囲 | 限界 |
| --- | --- | --- |
| CI の静的チェック(checkov / trivy) | Terraform コード上の設定ミス(暗号化なし、全開放 SG、IAM ワイルドカード等)を PR 時点で検出 | コード外で作られたリソースや、実行時の状態は見えない。tfsec は Trivy に統合されている旨を利用前に確認する |
| カスタム検証スクリプト | 組織固有の規則(タグ、リージョン、削除保護、クリーンアップ手順の有無) | 保守が必要。誤検出と見逃しは実行して確認するまで未確認 |
| 権限境界(IAM permissions boundary 等) | 作成される IAM ロールの上限権限 | 境界の外の既存ロールには効かない |
| 組織ポリシー(SCP / Azure Policy / GCP Org Policy) | アカウント・サブスクリプション・プロジェクト全体の禁止事項 | 単一アカウントの検証環境では使えない場合がある。一部の操作は SCP で拒否できない。導入には組織側の権限が必要 |
| 検知(アラーム、ログ) | 発生後の検知 | 予防ではない |
